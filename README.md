# Failure Simulation Tool

A FastAPI-based QA tool for simulating API failures and abnormal backend
behaviour.

See [Design v1](design-v1.md) for the product context, MVP scope, architecture,
and implementation plan.

## Current state

Iteration 1 provides a headless vertical slice:

- `GET /api/users` returns a simulated `503` response;
- all other HTTP requests are forwarded to the configured target API;
- `GET /health` reports whether the simulator process is running.

## Local development

The project requires Python 3.12 or newer.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/pytest
```

Start the simulator and point it at a running HTTP API:

```bash
TARGET_API_URL=http://localhost:9000 \
  .venv/bin/uvicorn app.main:app --reload --port 8080
```

Try the seeded failure rule:

```bash
curl -i http://localhost:8080/api/users
```

The response is generated by the simulator:

```http
HTTP/1.1 503 Service Unavailable
content-type: application/json

{"error":"service unavailable"}
```

Any other path is forwarded to `TARGET_API_URL`, including its HTTP method,
query parameters, body, and end-to-end headers. The target defaults to
`http://localhost:9000`; `UPSTREAM_TIMEOUT_SECONDS` defaults to `30`.
